# Overview of Code

To navigate my code, the main melody is the main part to follow (also found in Main Melody-Piano file)

This is the key feature of BreathBeat and the comments are used as instructions for TunePad to know what the reasonings are for the code and also for listeners, but they can also know through the rise and fall of the notes. 

The soft introduction and ending of the main melody act as 'warnings' in a way, sounding different and smaller durations to let you know that it is starting and ending. 

In my json file you can also see the code of the other supporting instruments but that is just for added layers to the song, it doesn't have a purpose in terms of the actual breathwork techniques.

# How To Run Code

You can run this code by opening TunePad and copy and pasting each code from my project files  into the cells that correlate with the right instrument. 

For example, you can open up a new project in TunePad, add a piano cell and copy the Main Melody-Piano code and past it into the cell and repeat for all the other instruments. 

You can toggle the different instruments to get the specific one from its main instrument, for example, choose the guitar cell and then press the drop down menu where it says "guitar" under the code cell and choose bass to get that instrument. The same goes for the crystal organ but just choosing the piano cell first, drop down menu and choosing "crystal organ"
